# Sentiment Analysis – Analyzing User Sentiments and Performance of Threads

## 📌 Overview

This project focuses on analyzing user sentiments and evaluating the performance of Threads using data analysis, machine learning, and visualization techniques. It includes a Jupyter Notebook for in-depth analysis and a Streamlit-based web application for real-time sentiment prediction.

---

## 📁 Repository Contents

- **`Analyzing User Sentiments and Performance of Threads.ipynb`**  
  Jupyter Notebook for sentiment analysis including data exploration, preprocessing, model training, and evaluation.

- **`sentiment_app.py`**  
  Streamlit web application for real-time sentiment classification of user reviews.

- **`threads_reviews.csv`**  
  Dataset containing user reviews from Threads.

- **`requirements.txt`**  
  List of all Python dependencies needed to run both the notebook and the application.

---

## 📊 Jupyter Notebook Features

- Data loading and inspection  
- Data cleaning (removal of duplicates, handling missing values)  
- Exploratory Data Analysis (EDA) using `matplotlib`, `seaborn`, and `plotly`  
- Text preprocessing (tokenization, stopword removal, lemmatization using `nltk` and `spacy`)  
- Visualization of sentiment distribution and review sources  
- Building a machine learning model using TF-IDF and SVM  
- Model evaluation using accuracy, precision, recall, and F1-score

---

## 🌐 Streamlit App Features

- Input box for user review text  
- Real-time text preprocessing and sentiment prediction  
- User-friendly interface to classify sentiments as **Positive**, **Neutral**, or **Negative**  
- Lightweight and interactive web-based application
